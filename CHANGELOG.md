# Changelog

All notable changes to ReverseIMG are documented here.

## [0.1.0] — 2026-10-26

### Added

- Firefox MV3 extension with reverse image search and keyword image search.
- Reverse engines: Google Lens, Bing, Yandex, TinEye, SauceNAO.
- Keyword engines: Google Images, Bing Images, Yandex Images, DuckDuckGo, Brave Images.
- Right-click image menu, optional full engine submenu, and selected-text image search.
- Popup with keyword search, recent searches, file upload, drag and drop, clipboard paste, and image URL.
- Offscreen upload handoff with IndexedDB temporary storage and 15-minute cleanup.
- Options page with engine enable/disable, default engine, ordering, theme, new-tab behavior, recent-search clearing, export/import, and reset.
- Localized UI in English, Russian, French, Spanish, Simplified Chinese, German, Brazilian Portuguese, and Hindi.
- Privacy policy page localized into all eight languages, full policy translations in `docs/privacy/`, and AMO data-collection declaration.
- Vitest tests, locale coverage checks, `web-ext` linting, and AMO packaging scripts.
